# Portfólio · Gabriel Henrique

Site pessoal em HTML, CSS e JavaScript puros.

## Estrutura

```
index.html
css/style.css
js/script.js
img/foto.jpg
```

## Publicar no GitHub Pages

1. Envie estes arquivos para a raiz de um repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
